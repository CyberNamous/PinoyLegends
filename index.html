About the game

Built for the ranked ladder

Pinoy Legends is a 5v5 competitive MOBA built from the ground up for fast decision-making, clean readability in team fights, and a hero roster designed to reward mastery over grind. Every system in the game — matchmaking, itemization, map design — is being stress-tested with the community before it reaches ranked play.

Skill-first combat

Clear counterplay windows and readable ability telegraphs, tuned so outplays come from decision-making, not obscurity.

Living balance

Alpha and beta data feeds directly into hero and itemization passes — the roster you test is the roster you help shape.

Built for the scene

Spectator tools, clean UI, and a roadmap toward organized competitive play from day one.

Testing roadmap

Three phases to launch

Access opens in stages. Each phase widens the player pool and narrows what's left to fix before Pinoy Legends goes live.

Phase 01

Closed Alpha

Small-scale invite testing focused on core combat feel, server stability, and first-pass hero balance.

Phase 02

Closed Beta

Expanded invites, ranked matchmaking prototypes, and the first community-facing balance patches.

Phase 03

Open Beta

Public access ahead of launch, with the roster, map, and systems locked toward their release state.

Be there for the first patch

The community server is where testing invites, patch notes, and balance discussions happen first. No spam, just the people building this game with us.
